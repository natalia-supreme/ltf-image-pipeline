# Approved Prompts — ad-hoc image generator reference

12 signed-off prompts. Paste any one into an image generator (FAL
nano-banana-2, or any text-to-image tool).

## What to input to run a test

For the **kit prompts** (head-to-head + single hero) replace 4 values:

- `[HOME PRIMARY]`   — home club main colour   (e.g. Arsenal → bright red)
- `[HOME SECONDARY]` — home club second colour  (e.g. Arsenal → white)
- `[AWAY PRIMARY]`   — away club main colour   (e.g. Burnley → deep claret)
- `[AWAY SECONDARY]` — away club second colour  (e.g. Burnley → sky blue)

Colours come from `team_colours.yaml`. The **atmosphere prompts**
(ball-motion, fan-pov, pitch-tunnel, epic-bowl) need NO inputs — paste
as-is. Output: square 1200×1200 (crop after if the model ignores size).

Minimum to run a test = 1 prompt + (for kit prompts) the 4 colour values.
